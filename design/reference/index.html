// tools

The rtf* family

Self-hosted .NET tools for working alongside AI agents, wired in through MCP and Claude Code. Each name is the polite reading of an impolite acronym.

rtfm

Retrieval Tool For Manuals

v1.13 · MIT
  • cli
  • mcp server

Local documentation search for AI agents. Indexes Confluence exports, Word, PDF, Markdown, spreadsheets, diagrams and database schemas into OpenSearch on your machine, then serves hybrid search over MCP.

# make AI agents read the manual
$ dotnet tool install -g Rtfm.Cli
$ dotnet tool install -g Rtfm.Mcp
$ rtfm init
github.com/a7ex-turcan/rtfm ↗

rtfq

Remote Tool For Queries

early · v0.1 · MIT
  • server
  • cli
  • mcp server

One self-hosted binary between your agents and PostgreSQL, SQL Server, MongoDB or allow-listed HTTP APIs. Callers see only what they're granted, writes wait for an unlock and a human approval, and every request is audited.

# read by default, write on a leash
$ rtfq serve
$ rtfq approvals
github.com/a7ex-turcan/rtfq ↗ releases ↗

rtfc

Relay Tool For Contacts

early · v0.3 · MIT
  • claude code plugin
  • daemon
  • cli

Claude Code to Claude Code messaging between people. Contacts are mutual, messages park in your status bar until you read them, auto-answer is opt-in per contact, and every connection is mutual TLS on your LAN.

# stop copy-pasting between terminals
$ rtfc init
github.com/a7ex-turcan/rtfc ↗ releases ↗

rtfd

Read The Fine Diff

in the lab · MIT
  • watcher
  • any agent

A pull-request review watcher for any AI agent. It hands each PR to Claude Code, Copilot CLI or whichever agent you configure, runs it read-only, and posts one review with inline comments back to the PR.
